## 二、技术架构

```
Playwright 持久化 profile + cookies.json
  → 页面内 fetch POST（Cookie/Referer 与前端一致）
  → 选品中心真实接口
  → JSONL 断点落盘
  → openpyxl 导出 Excel（双行中英表头）
```

### 核心接口

| 接口 | 用途 |
|------|------|
| `/manager/Choice/getGoodsList` | 商品列表（nav 分区 / 关键词 type=1） |
| `/manager/Choice/getGoodsDetail` | 详情、sku_list、no_deliver |
| `/manager/Choice/getBannerImg` | 首页轮播图 |
| `/manager/choice/getTopSpecial` | 首页轮播侧栏商品（含团购爆品 goods_list） |
| `/manager/Choice/getRecsSpecial` | 每日必看入口 |
| `/manager/Choice/free_shipping` | 特定包邮地区 |
| `/manager/Choice/getUserInfo` | 登录态（sys_id=11 / is_tourist=1 为试用或游客） |

### 分区 nav_id

- 团购爆品：`11`
- 海量优品：`7`（无权限时回退全站 getGoodsList）
- 每日必看：getRecsSpecial 返回的各 nav_id（酒水、个护家清等）

## 五、当前业务规则

1. 排除京东仓：`supply_type==1` 或渠道名含「京东」
2. Excel 表头双行：第 1 行英文键，第 2 行中文说明；数据自第 3 行
3. 包邮：接口 `1=包邮，2=不包邮或按地区`；交付表只保留可读「包邮结论」
4. 同名同 SKU 多 goods_id：分组、组内按代发价排序、保留组内 ID 列表
5. 组合商品（组合/套装/礼盒/带米/调味品/多油种拼搭/2+1 等）**只进组合分表**，不得出现在单品子类表
6. 油类子类对齐京东/淘宝「粮油 > 食用油」；牛油果油 ≠ 牛油；火锅牛油不计入食用油
7. 长任务输出进度 + ETA，并写 `output/progress_status.txt`
8. 采集前页面加载等待约 3.5 秒
9. 商品编码使用 `spu_sn` / `goods_sign`（G+大写），不用 `goods_sn`
10. 多 SKU：详情 `sku_list` 一 SKU 一行
