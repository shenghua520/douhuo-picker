# 抖货选品数据获取经验总结

> 适用于：douhuomall / 微唯宝选品中心 → Excel 批量采集与清洗

## 1. 登录与会话

1. 选品页是 Vue SPA + Cookie 会话；**游客/试用（sys_id=11）拿不全数据**，专栏常返回 `1014 权限不足`。
2. Playwright 持久化 profile **不保证**会话 Cookie 落盘；必须在登录成功后 **显式导出 cookies.json**，采集启动时 `add_cookies` 注入。
3. 登录态会过期：每次跑批前检查 `getUserInfo`，`is_tourist=1` 或 `sys_id=11` 要先重新 `--login`。
4. 打开页面后建议 **等待 3~4 秒** 再请求，降低价格/库存未就绪概率。

## 2. 接口与字段

5. 列表接口 `getGoodsList` 用页面内 `fetch` POST JSON（带 Cookie/Referer），不要裸 requests。
6. 商品编码用 **列表 `spu_sn` / 详情 `goods_sign`（G+大写）**，不要用 `goods_sn`（可能混写或像数字 ID）。
7. `is_freight`：`1=包邮，2=不包邮或按地区`；**不是 0/1**。
8. 不包邮/不发货地区：详情 `no_deliver`；特定包邮地区：`free_shipping` 接口。业务表往往只需要可读的 **「包邮结论」**，原始三列可删。
9. 分页 `limit=100` 可用；全站 12 万+ 时约 0.3~1s/页，要 **断点续跑（JSONL+progress.json）**。
10. 专区过滤：`nav_id`（团购爆品=11，海量优品=7，每日必看各专区另有 id）；`getTopSpecial` / `getRecsSpecial` / `getBannerImg` 对应首页区块。
11. 首页轮播「右侧商品」来自 `getTopSpecial.goods_list`；banner 图 `link_url` 里是 **专区 id**，要再调 `getGoodsList` 才能拿到跳转页商品。

## 3. 采集与进度

12. 长任务必须：**日志 + ETA + `progress_status.txt`**，至少每 5 分钟一次可感知进度。
13. 大类拆分抓取（如油品 30+ 关键词）比一次全站翻页更快、更好过滤。
14. 同一 API 对试用账号可能只回部分字段；正式账号结果更完整。

## 4. 清洗与分类（教训）

15. **关键词「含油」≠ 食用油**：牛油果护唇膏、火锅底料牛油、油壶、酱油都会被误抓。
16. 分类应 **对齐京东/淘宝粮油>食用油** 一级类目（菜籽油/花生油/玉米油/…），细分（浓香/低芥酸）放「子类细分」。
17. `牛油` ≠ `牛油果油`；火锅「牛油」不是食用油 SKU。
18. 同名同 SKU 多 `goods_id`：按「规范化名称+SKU」分组，按 **代发价降序** 并保留 `组内goods_ids`。
19. **组合/礼盒/带米/调味品** 必须单独分表，禁止散落在单品子类表中。
20. 排序业务常用：**规格（体积 ml/L）→ 代发价**；规格要归一化（5L/500ml），修 OCR 混淆（25OML→250ml）。
21. 多 SKU 商品：详情 `sku_list` **一 SKU 一行**，带 `SKU编码`/`SKU规格说明`。
22. Excel 表头双行：第 1 行英文键、第 2 行中文；说明表写清取值（包邮 1/2、渠道类型 id）。
23. 商品名可能含非法 XML 控制字符，写 openpyxl 前要清洗。
24. 采集时间放 **文件名**，不要占一列（除非审计需要）。
25. 人工列（京东价、价差、是否选品）与抓取列分离，重跑脚本时不要覆盖人工列。

## 5. Excel 与交付

26. 先 JSONL 落盘再导出 Excel，中断可续，便于重导/改字段不重抓。
27. 大表（10 万行）导出前确认磁盘与 openpyxl 内存；12 万行 xlsx 约 20~30MB。
28. 每个交付工作簿带：**字段说明 + 统计/分布 + 审核用剔除清单**。
29. 业务要求会快速迭代：字段增删、组合拆表、排序规则 → 脚本化比手工改表稳。

## 6. 工程与协作

30. GitHub Actions 需要仓库根目录 **`requirements.txt`**（setup-python `cache: pip` 才能过）。
31. GitHub **纯中文仓库名会被 API 清成 `-`**；用英文 repo 名 + 中文 Description。
32. 本机 git push GitHub 可能被墙/重置，可改 **GitHub REST API（blobs/trees/commits/ref）** 推送。
33. PAT 只进本机配置，**不要提交进仓库**；上传前对远端做敏感词扫描。
34. review 不能只看识别率：必须 **抽样人工读标题 + 硬排除名单 + 剔除清单可审计**。

## 7. 本次油类任务要点（可复用）

35. 数据源关键词：菜籽油/玉米油/花生油/… + 食用油/非转基因 等 30 个左右。
36. 识别率目标：子类 ~100%，规格 ~97%+，品牌词典+前缀启发 ≥80%，组合单独表。
37. 终态表结构示例：字段说明 / 食用油单品全量 / 组合_礼盒_套装 / 各标准子类表 / 统计。
38. 最终可删冗余运费原始列，只留 **「包邮结论」** 一列给业务。
